Export

An export with the Spektrafilm effect renders each photo again, at full quality, with the settings saved for its variant. The preview in the Viewer uses the same settings; judge grain and effects calculated in pixels (Micro contrast, Glare blur) at 100% zoom or at Native resolution.

With the neutral input, the image contains no C1 sharpening from the Sharpening tool. You set sharpness in the panel (chapter 9, Sharpness). The ordinary C1 export also adds the recipe's output sharpening (Screen and Print modes), as it does without Spektrafilm; the panel's export buttons do not.

Presets and LUT export

Exports the current photo at full size. It suggests the name name-Spektrafilm and the format from Export file format. With several photos selected it switches to batch export.

Export selected TIFFs…, Export selected PNGs…, Export selected JPEGs…, Export selected DNGs…, Cancel export

Below the list of panel sections

Batch export of the selected variants to a folder you choose. Each variant uses its own saved Spektrafilm settings. Variants with Spektrafilm switched off are exported with the C1 development only. Files are named name-Spektrafilm; when such a file already exists, the panel picks a free name, so nothing is overwritten. Cancel export stops the batch, and finished files are kept.

Ordinary Capture One export

File › Export, Export with previous

When the selected photo has Spektrafilm switched on, the C1 export writes the Spektrafilm image through C1's export recipes. The C1 export window has "Spektrafilm" added to its title. After you click Export, the panel lists the files, and after you confirm it renders the photos and hands them to C1 to write.

What comes from the recipe
  • Recipes: the same ones C1 would use, several at once if you like. Each gives its own file.
  • Location and name: folder, subfolder and a file name from tokens (for example [Image Name], the date, the recipe name), worked out by the same function as in C1. A counter in the name gives all files of one image the same number, as in C1; a cancelled list uses no numbers.
  • Format: JPEG, TIFF 8 or 16 bit, PNG, PSD and PSB, with the compression and quality from the recipe. Linear DNG is written by the panel (without the recipe's metadata and watermark).
  • ICC profile from the recipe. With sRGB and Adobe RGB, C1 only writes the panel's pixels; with any other profile (a printer, eciRGB), the panel renders in 16-bit ProPhoto RGB and C1 converts to the recipe's profile.
  • Size (scale, long edge and so on) and resolution (dpi).
  • Metadata of the photo, following the recipe's switches: camera data, copyright, rating, GPS, keywords.
  • Watermark, text (with tokens) or image, in the same place and size as in an ordinary C1 export.
  • Output sharpening (Screen, Print).
  • Crop as a path (Crop › As path): the file holds the whole photo and the crop path, for example in PSD. When scan geometry or a paper border reshapes the image, the panel applies the crop instead of the path and says so in the list.

A photo is rendered once for each group of recipes with the same size, crop and colour space, so several recipes do not make the export several times longer.

The list before the export

The Export with recipes window shows every file: photo, recipe, name, folder and what will happen: New file, Renamed (the name was taken), Replaces the existing file or Skipped. The export starts only with Export. Show this list before every export turns the list off for later exports; it still appears when a decision about an interrupted export is needed.

When a file already exists

The recipe's setting decides: rename (name_1, name_2, as in C1), replace or skip. The panel never replaces the original photo or a file written earlier in the same export; in that case it picks a free name. Each file is written under a temporary name and gets its real name only when it is complete.

An interrupted export

The progress of an export is saved as it goes. When you stop an export (Cancel export), when a file cannot be written or when C1 is closed, the button Resume interrupted export (N files)… appears below the panel sections. Resuming writes only the missing files, under their planned names, with the current Spektrafilm settings of those photos. The resume window also lets you drop the interrupted export (Discard interrupted export). The photos must be in the collection shown in the C1 browser.

The look in the metadata

When the recipe writes other metadata (Metadata › Other), the file also gets a description of the Spektrafilm look: film, paper, mode, exposures and Look strength, in its own XMP fields (spektrafilm:). Programs that read XMP show them next to the data from C1.

Pitfalls
  • The preview in the C1 export window does not show the Spektrafilm effect; the effect is in the file.
  • Original recipes (a copy of the original) and Affinity recipes are not processed images, so the panel does not write them and marks them in the list.
  • C1 16.9 writes 16-bit PNG with its bytes swapped; the panel detects this and corrects the file.
  • When no selected photo has Spektrafilm switched on, the ordinary C1 export runs. With a mixed selection, variants with Spektrafilm switched off are written with the C1 development only, through the same recipes.
  • In a C1 version other than 16.9.0.3894, when functions it needs are missing, the panel falls back to the earlier way: it asks where to save and needs exactly one selected recipe.
  • When the panel cannot take over the C1 export, it shows an orange message at the top of the panel. In that case the C1 export would save files without film, so use the export buttons in the panel.

Format and colour

Export file format

Spektrafilm optics › Color management

Options
Use C1 recipe format (TIFF if unavailable), TIFF 16-bit, PNG 16-bit, JPEG 8-bit, Linear DNG 16-bit Rec.2020
Default
Use C1 recipe format

Applies to the panel's export buttons. The ordinary C1 export takes the format from the recipe.

  • TIFF and PNG keep the full 16-bit precision. TIFF for further editing and printing.
  • JPEG is 8-bit and lossy. For the web and previews.
  • Linear DNG saves linear Rec.2020 data with highlight headroom, regardless of the chosen profile. For further editing in a program that reads DNG.

Export profile / compression target

Spektrafilm optics › Color management

Default
sRGB
Options
17 colour spaces, including sRGB, Adobe RGB, ProPhoto, Display P3, Rec.2020, ACES2065-1, DaVinci Wide Gamut, V-Gamut and their linear versions

The profile of files from the panel's export buttons; the ordinary C1 export uses the recipe's profile. The preview in the Viewer is always in sRGB (before monitor correction), so it is not a full preview of a wide gamut.

When to use
  • sRGB: the web, screens, most labs.
  • Adobe RGB, ProPhoto RGB, Display P3: printing and further editing in a wide gamut.
  • DaVinci Wide Gamut, V-Gamut, ACES: video and grading. The logarithmic DaVinci and V-Log versions are saved without an embedded profile, so you must set the colour space in the target program.
Pitfalls

The output compression in the Color adaptation section (Output lightness compression and Output chroma compression) fits the image into sRGB, also when you export to a wider profile. Measurement on a saturated colour chart (Ektar 100 on Endura Premier): with compression on, no pixel falls outside sRGB, so an Adobe RGB or ProPhoto file contains only sRGB colours. With both switches off, 55% of the chart has colours outside sRGB and a wider profile keeps them. Switch both off together: with only Output chroma compression off, colours are hard-clipped at the sRGB boundary. When you export to sRGB, leave both on.

What depends on the output size

Most of the simulation is calculated in micrometres on the film, so it looks the same at any size. A few things, however, depend on the number of pixels in the output.

ElementBehaviour in a smaller file
Micro contrastHas a fixed radius in pixels, so in a small file it acts on larger structures and looks stronger.
Glare blur (px)Also in pixels: the same value is wider in a small file.
Preview, Production and RMS grainDownsizing averages the grain, so it is weaker. Keep average colour under grain makes sure the colour does not change.
Grain synthesisWith Match grain to output size, Remove sampling noise and Blur grain as light, a smaller output has the grain colour and strength of a downsized full-resolution image (difference in strength up to about 10%).
Scanner sharpening, halation, diffusionCalculated in micrometres, so proportional to the frame. In a small file, fine effects become smaller than a pixel and disappear.

Judge a look for a specific size at that size: set Viewer resolution close to the target width, or make a test export through a C1 recipe of that size.

Limits

  • Up to 100 MP and 16,384 px per side. A larger export ends with a message asking for a smaller size.
  • Grain synthesis up to 32 MP. For a larger export, change the grain model to Production or reduce the size.
  • One C1 crop per variant. A crop that extends beyond the image must be moved inside the photo.

LUT export

Export color-only 33-point LUT…, Export color-only 65-point LUT…

Presets and LUT export

Saves the look as a 3D LUT (.cube or .3dl), with sRGB input and output. 33 points are enough in most programs; 65 is more accurate. The LUT buttons work only when Spektrafilm is switched on for the current photo; otherwise they do nothing.

Export Hald CLUT…, Export OCIO bundle…

Presets and LUT export

The same look as a Hald CLUT image (PNG, level 8) for programs that read it, or as an OpenColorIO bundle (a folder with a configuration and a LUT).

What a LUT does not contain

A LUT contains the film and paper simulation, the colour and tone from finishing, and Look strength. It does not contain micro contrast, automatic exposure metering, grain, spatial effects (halation, diffusion, glare), geometry or the input preparation in C1. So a LUT cannot reproduce the full look from the Viewer; it works best on images prepared in a similar way as in C1.

Checklist before export

  1. Look checked in the preview, for grain and sharpness at 100% zoom (Viewer resolution = Auto or Native resolution).
  2. Format and profile set in the C1 recipe (ordinary export) or in Color management (panel buttons).
  3. For a series: look copied to all photos (Copy look), brightness checked on a few of them.
  4. Export with an ordinary C1 export (the list before the export shows the files and any name collisions) or with a panel button.
